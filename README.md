# Student Job Portal

A full-stack job portal developed using Java, Spring Boot, JSP, Servlets, Hibernate, and MySQL.

The application provides separate workflows for students and recruiters. Students can browse jobs, apply for jobs, upload resumes, and track applications. Recruiters can post jobs, manage their jobs, view applications, and update application statuses.

## 🚀 Features

### Student Features
- Student registration and login
- Browse available jobs
- View job details
- Apply for jobs
- Prevent duplicate job applications
- Upload resume in PDF format
- View profile
- Track submitted applications
- View application status

### Recruiter Features
- Recruiter registration and login
- Recruiter dashboard
- Post new jobs
- Edit existing jobs
- Delete jobs
- View posted jobs
- View received applications
- View applicant resumes
- Update application status
- Application statuses:
  - Applied
  - Shortlisted
  - Interview
  - Selected
  - Rejected
